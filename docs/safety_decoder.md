# 当前合法候选与评分后的安全续接

当前主流程由 `candidates.py`、`gnn.py`、`scheduler.py`、`continuation.py` 和 `dispatch.py` 组成：先生成当前合法动作，按费用评分和消息精化排序，再为有限数量的领先候选构建后续可行计划。被评分动作与最终接受计划的首动作保持完全一致。

旧逐点收缩解码器已移除。续接所需的公共约束与补偿上下文由 `continuation.py` 准备，候选生成阶段只处理当前动作；通过评分后验收的候选才生成可执行的剩余计划。

## 1. 物理状态与备用计划

时刻为 \(t\)，全局步数为 \(T\)，费用预测窗口为 \(W\)，续接窗口为 \(W_s\)，实际续接长度为 \(L=\min(W_s,T-t)\)。状态包含各罐库存和上一时刻泵功率。`anchor` 是从当前状态到全局终点的已验收备用计划。初始备用由恒库存参考构造并独立检查；每次执行后保留已接受计划的后缀。

热泵 \(i\) 固定接储罐 \(s(i)\)，多个热泵可连接同一罐。储罐和建筑允许多对多边。固定COP模型的能量递推为

\[
E_{s,k+1}=a_s E_{s,k}+\Delta t\left(
\eta_s^c\sum_{i:s(i)=s}\mathrm{COP}_i P_{i,k}
-\frac{\sum_{e:s\to b}F_{e,k}}{\eta_s^d}
-U_s(T_s^{\mathrm{ref}}-T_{s,k}^{\mathrm{env}})\right),
\quad a_s=1-\frac{\Delta t U_s}{C_s}.
\]

\(E\) 为参考温度之上的储热量，单位kWh；\(P\) 为电功率，\(F\) 为有效供热功率，单位kW；\(\Delta t\) 为小时；\(\eta^c,\eta^d\) 为充放热效率；\(U\) 为kW/K散热系数；\(C\) 为kWh/K热容量；\(T^{\mathrm{ref}},T^{\mathrm{env}}\) 为储热参考温度与罐周围温度。

共同约束包括设备上下限和爬坡、供热边容量、逐栋需求、各罐库存与充放热容量、站内热源及总电功率带。外部需求和天气在当前实验中已知。

## 2. 轻量候选与稳定ID

每轮生成 \(N\) 个固定加扰Sobol序列前缀点，\(N\) 为2的幂，另加入第0个备用动作。缓存仅复用超立方体坐标；每轮按实际库存和上一功率重新映射。

首先求各泵运行/爬坡区间，再借助备用供热分配收紧为具有物理可行见证的初始功率盒。总功率采样后按剩余上下界逐泵分配：

\[
p_\Sigma=L_P+(U_P-L_P)\zeta_0,
\qquad \rho_i=p_\Sigma-\sum_{j<i}P_j,
\]
\[
\ell_i=\max\left(\underline P_i,\rho_i-\sum_{j>i}\overline P_j\right),
\quad u_i=\min\left(\overline P_i,\rho_i-\sum_{j>i}\underline P_j\right),
\quad P_i=\ell_i+(u_i-\ell_i)\zeta_i.
\]

\(L_P,U_P\) 是本轮初始盒和总功率带共同允许的总量区间；\(\underline P_i,\overline P_i\) 是初始盒中的设备区间；\(\rho_i\) 是剩余总量；\(\ell_i,u_i\) 为条件区间；\(\zeta\in[0,1]\) 来自Sobol坐标。最后一台热泵领取剩余量。

随后进行保持总功率的成对功率转移，并在每栋建筑入边间进行保持需求的供热转移。转移区间直接由当前设备、热源、罐容量和库存余量确定。它允许离开初始功率盒，但总功率仍来自该盒的总量区间，因此属于有明确覆盖限制的可行探索。

最后重新计算联合物理量，过滤当前违法点并去重。每个候选只保存当前 \(P,F\)、后继库存与ID。备用ID为0，其他ID为原始Sobol行号加1；拒绝和去重保留已有ID。固定模式、种子、映射和设备顺序时，增加前缀保留旧候选。原始点数、合法点数、重复点数和实际池大小分别记录。

## 3. 费用评分与消息精化

所有模式使用同一候选池和精确当前电费：

\[
\widehat J_t(a)=\Delta t\,c_t\sum_iP_i+\widehat V_t(a).
\]

\(c_t\) 为元/kWh电价；\(\widehat V_t(a)\) 为网络预测的后续窗口费用，单位元。最终时段的未来费用严格为零。完整、粗和混合评价器保留相同四角色物理消息，只替换选定充热边的学习部分；完整消息在选定位置后才计算。

离线教师标签固定当前动作，通过共同窗口LP求后续最低电费。LP标签用于教师训练；粗分支用冻结教师的相对决策损失训练。不同图规模先按储罐数归一化费用，温度对应的尺度由训练集确定并固定。候选续接计划自身的费用不作为网络输入或标签。

## 4. 对同一个动作构造后续计划

每轮按最终评分顺序最多尝试 `control.max_continuation_attempts` 个候选。备用动作可复用已有证书。其他候选的处理顺序为：

1. 把候选原样放入局部计划的第一个时段，保留未来供热分配。
2. 在后续泵功率上构造爬坡连接，朝备用计划返回；未到全局终点时，窗口最后一步功率与备用一致。
3. 计算窗口末库存相对备用的差，利用未来泵功率余量补偿。
4. 最多尝试均匀余量、偏早余量、偏晚余量三类时间分配，并独立回放改变窗口。
5. 检查通过后才拼接不变尾段；执行时再次核对首动作与被评分候选逐元素相同。

库存补偿的线性构造可以写为

\[
\Delta E_s=E^a_{s,t+L}-E^{\mathrm{base}}_{s,t+L},
\quad R_s=\Delta t\,\eta_s^c\sum_{k=0}^{L-1}
 a_s^{L-1-k}w_k\sum_{i:s(i)=s}\mathrm{COP}_i r_{i,k},
\]
\[
P^{\mathrm{trial}}_{i,k}=P^{\mathrm{base}}_{i,k}
+r_{i,k}w_k\frac{\Delta E_{s(i)}}{R_{s(i)}}.
\]

上标 \(a\) 表示已验收备用；`base` 为爬坡连接后的局部计划；\(r_{i,k}\ge0\) 是按所需增减方向确定的功率余量；\(w_k>0\) 是三个时间分配之一；\(R_s\) 是该分配的窗口末库存响应。首步余量固定为零；需要连接外部尾段时，局部末步余量也为零。零响应且存在非零补偿需求时，本次构造失败。

该公式使候选首动作保持原样，并针对目标库存构造未来功率。它产生的是待验收提议，最终设备、库存、热源、总功率和所有爬坡约束由独立物理回放决定。

一次构造失败记为UNKNOWN，表示这套有限搜索没有找到证书。它不证明当前候选不存在其他可行延续。所有尝试失败或整轮超时时执行原备用动作，记录实际候选ID为0及回退原因。

## 5. 计时与结果解释

- `candidate_raw_count`、`raw_feasible_count`、`candidate_duplicate_count`：原始取点、当前合法原始点和重复点统计。`candidate_pool_size` 是保留备用后的实际池大小。
- `score_preferred_candidate`：评分第一名的稳定候选ID；`selected_candidate`：实际执行候选ID。GNN故障回退时执行ID为0，评分第一名仍独立记录。
- `refined_messages`、`total_messages`、`refinement_fraction`：消息精化数量与比例；`scoring_steps` 保存每轮优先级分组执行和时间信息。
- `continuation_attempt_count`、`window_replay_count`：尝试的候选数和实际独立回放次数；提前构造失败没有回放，备用证书复用也不重复回放。
- `continuation_unknown_count`、`continuation_unknowns`：有限续接未找到证书的次数与原因。
- `anchor_selected_count`：排序验收主动接受备用；`anchor_action_count`：实际动作与备用相同，包括自然相同、主动接受和回退。
- `fallback_count`、`fallback_reasons`、`execution_reason`：异常、整轮超时或有限续接失败后的备用执行。
- `solver_calls`：在线LP求解次数，GNN路线应为零。离线标签、神经训练和延迟校准成本另列。

`inference_time_s` 包含当前物理/上下文准备、基础评分、误差估计、梯度、调度、缓存和精化；`score_*` 字段进一步分解这些计算。候选生成和评分后续接验收单独计时。首次公共延迟包括参考计划构造、验收和模型装载。`control_time_s` 等于公共单次延迟之和，失败决策尝试的时间同样计入。

评分预算与整轮控制时限分别记录。中位延迟预测可能低估实际增量耗时；报告保存评分超限、重新校准需求及整轮超时。物理环境推进和周末的独立轨迹审计单列，最终总电费仅在完整执行轨迹验收通过后报告。
