# 南京 CSWD 周天气

原始文件来自 [Climate.OneBuilding 南京 CSWD](https://climate.onebuilding.org/WMO_Region_2_Asia/CHN_China/JS_Jiangsu/CHN_JS_Nanjing.582380_CSWD.zip)，站号 582380。原 ZIP 随数据保存，`manifest.json` 记录 ZIP、内部 EPW 和派生 CSV 的 SHA256。CSV 仅提取 EPW 第 2、3、4、7 列，即月、日、结束小时和室外干球温度。

CSWD 是用于建筑模拟的典型气象年，由代表性月份组成。这里的连续七天是典型年中的七天片段，结果适用于这些天气场景。EPW 中的年份及原日历星期不参与住宅占用生成；每个实验周统一赋予周一 00:00 起点。源数据时间为 UTC+8 本地标准时。EPW 01:00 至 24:00 观测按结束小时定位，线性插值到控制周期左端的 00:00、00:30、…、23:30；年界按典型年周期衔接。

固定从 11 月 1 日起按七天切分，至 3 月 27 日获得 21 个互不重叠候选块。筛选仅检查默认设备与需求配置下，seed 42 的 S1–S5 恒库存参考轨迹是否通过独立物理验收，包含供热、设备界限、源热、总功率带、爬坡和终态；筛选未使用控制器经济效果。12 个候选通过，依时间次序保留前 11 个。全部通过／失败记录在 manifest。较暖周可能受全天开机及最低总功率限制而失败，这个筛选界定了当前可行基准场景，不能解释为暖周真实系统不可运行。改变设备、需求或种子后仍应构造并验证参考轨迹。

训练、调参和最终测试按完整周隔离；相同 week_id 的天气在全部尺度和随机种子下完全相同。划分只提供当前典型年内的天气场景评估，独立实测年份泛化需要额外数据。

住宅占用日程采用工作日 07:00 前、20:00 后占用，周末全天占用，并在边界中心作一小时线性过渡（06:30—07:30、19:30—20:30）。日程依据 Arroyo 等的 [RL-MPC §5.1](https://doi.org/10.1016/j.apenergy.2021.118346)。需求增益 `gamma=0.10` 和固定参考温差 15°C 是本实验的净需求假设：`Q_b(t)=0.45 Qnom_b f_b max(20−Tout(t),0)/15 × (1+gamma o(t))`。它将日历变化映射为外生热需求，未分别计算人员内部得热、生活热水用量和室内温度；周末增益不等于普遍住宅实测结论。整个星期不重新按平均负荷归一化，储罐状态跨日连续。工业源侧和地下罐环境温度使用独立参数。
